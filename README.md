# 🏠 Парсер квартир в новостройках с Циан

Веб-приложение для парсинга и анализа квартир в новостройках с сайта Циан с удобной таблицей, фильтрацией и сортировкой по цене за квадратный метр.

## Возможности

- 🔍 **Парсинг новостроек** - Автоматический сбор данных о квартирах в новостройках с Циан
- 📊 **Таблица с данными** - Удобное отображение всех собранных объявлений
- 🎯 **Фильтрация** - Фильтруйте квартиры по цене, площади и цене за м²
- 📈 **Сортировка** - Сортируйте по любому параметру (цена за м², общая цена, площадь)
- 💰 **Расчет цены за м²** - Автоматический расчет стоимости квадратного метра
- 📥 **Экспорт данных** - Выгружайте результаты в CSV или Excel
- 📱 **Веб-интерфейс** - Удобный интерфейс на базе Streamlit

## Установка

### Требования

- Python 3.8 или выше
- pip

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd cian
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск приложения

Запустите приложение командой:

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## Использование

### 1. Настройка параметров парсинга

В боковой панели настройте параметры:

- **Город** - укажите город для поиска (по умолчанию: Москва)
- **Страницы** - задайте диапазон страниц для парсинга (максимум 54)
- **Количество комнат** - выберите интересующие варианты (1, 2, 3, 4, 5, 6)
- **Дополнительные фильтры** - установите минимальную/максимальную цену и площадь

### 2. Запуск парсинга

Нажмите кнопку **"🚀 Начать парсинг"** для запуска сбора данных.

### 3. Анализ данных

После завершения парсинга вы увидите:

- **Статистику** - общее количество объявлений, средние цены и площадь
- **Таблицу с данными** - все найденные квартиры
- **Фильтры** - слайдеры для фильтрации по цене, площади и цене за м²
- **Сортировку** - возможность сортировать по любому параметру

### 4. Экспорт

Используйте кнопки внизу страницы для экспорта данных:

- **Скачать CSV** - для работы в Excel/Google Sheets
- **Скачать Excel** - готовый Excel файл

## Структура данных

Приложение собирает следующую информацию о каждой квартире:

- Жилой комплекс
- Количество комнат
- Площадь (м²)
- Цена (₽)
- **Цена за м² (₽)** - рассчитывается автоматически
- Этаж
- Район
- Метро
- Ссылка на объявление

## Ограничения

- Циан отображает максимум 54 страницы результатов (~1,512 объявлений)
- Для получения большего количества данных рекомендуется делать несколько запросов с разными параметрами
- Скорость парсинга зависит от количества страниц и нагрузки на сайт Циан

## Технологии

- **cianparser** - библиотека для парсинга Циан
- **Streamlit** - фреймворк для создания веб-интерфейса
- **pandas** - обработка и анализ данных
- **openpyxl** - экспорт в Excel

## Примечания

- Приложение использует официальную библиотеку cianparser
- Данные собираются в реальном времени с сайта Циан
- Рекомендуется использовать разумные интервалы между запросами

2. Убедитесь, что все зависимости установлены
