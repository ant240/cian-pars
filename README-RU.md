# 🏠 Парсер квартир в новостройках с Циан

Веб-приложение для парсинга и анализа квартир в новостройках с сайта Циан с удобной таблицей, фильтрацией и сортировкой по цене за квадратный метр.

## 🚀 Быстрый старт для Windows

### Шаг 1: Проверьте Python
Дважды кликните на файл **`check-python.bat`**

- Если видите "Python is installed correctly" - переходите к Шагу 3
- Если видите "Python is NOT installed" - переходите к Шагу 2

### Шаг 2: Установите Python (если нужно)

1. Скачайте Python: https://www.python.org/downloads/
2. Запустите установщик
3. ⚠️ **ВАЖНО**: Поставьте галочку **"Add Python to PATH"**!
4. Нажмите "Install Now"
5. **Перезагрузите компьютер**

### Шаг 3: Запустите приложение

Дважды кликните на файл **`start.bat`**

Всё! Приложение откроется в браузере.

## 📁 Файлы для запуска

- **`check-python.bat`** - Проверить, установлен ли Python
- **`start.bat`** - Запустить приложение (всё автоматически)
- **`start-simple.bat`** - Простой запуск (если уже всё установлено)
- **`install.bat`** - Только установить зависимости

## ❗ Если не работает

### Проблема: "Python is not recognized"
**Решение:**
1. Установите Python с https://www.python.org/downloads/
2. При установке поставьте галочку "Add Python to PATH"!
3. Перезагрузите компьютер
4. Запустите `check-python.bat` снова

### Проблема: Ошибки кодировки в bat файлах
**Решение:**
1. Используйте `check-python.bat` для проверки
2. Затем используйте `start-simple.bat` для запуска
3. Или откройте папку проекта, в адресной строке введите `cmd`, затем:
   ```cmd
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
   ```

### Проблема: Ничего не происходит
**Решение:**
1. Кликните правой кнопкой на bat файл
2. Выберите "Запуск от имени администратора"

## 💻 Запуск через командную строку

Если bat файлы не работают:

1. Откройте папку проекта в проводнике
2. В адресной строке введите `cmd` и нажмите Enter
3. Выполните команды:

```cmd
# Проверить Python
python --version

# Установить зависимости (только первый раз)
python -m pip install -r requirements.txt

# Запустить приложение
python -m streamlit run app.py
```

4. Откройте в браузере: http://localhost:8501

## 🎯 Как использовать приложение

1. Запустите приложение (start.bat)
2. В боковой панели выберите:
   - Город (например, Москва)
   - Количество страниц для парсинга (1-54)
   - Количество комнат (1, 2, 3, и т.д.)
3. Нажмите "🚀 Начать парсинг"
4. Используйте фильтры и сортировку для анализа данных
5. Скачайте результаты в CSV или Excel

## 📊 Собираемые данные

- Жилой комплекс
- Количество комнат
- Площадь (м²)
- Цена (₽)
- **Цена за м² (₽)** - автоматически рассчитывается
- Этаж
- Район
- Метро
- Ссылка на объявление
