# 🏠 Инструкция по запуску для Windows

## Предварительные требования

1. **Python 3.8 или выше** должен быть установлен
   - Проверьте: откройте командную строку (cmd) и введите `python --version`
   - Если Python не установлен, скачайте с https://www.python.org/downloads/
   - При установке обязательно поставьте галочку "Add Python to PATH"!

## Способ 1: Автоматический запуск (Рекомендуется)

1. Клонируйте или скачайте репозиторий
2. Откройте папку проекта в проводнике Windows
3. Дважды кликните на файл `start.bat`
4. При первом запуске установятся все зависимости
5. Приложение откроется в браузере автоматически

## Способ 2: Ручной запуск через командную строку

### Шаг 1: Откройте командную строку в папке проекта

**Вариант А:** Через проводник
- Откройте папку с проектом в проводнике Windows
- В адресной строке проводника введите `cmd` и нажмите Enter
- Командная строка откроется сразу в нужной папке

**Вариант Б:** Через команду cd
```cmd
cd C:\путь\к\вашему\проекту\cian
```

### Шаг 2: Установите зависимости (только первый раз)

```cmd
python -m pip install -r requirements.txt
```

Если возникает ошибка с pip, сначала обновите pip:
```cmd
python -m pip install --upgrade pip
```

### Шаг 3: Запустите приложение

```cmd
python -m streamlit run app.py
```

Или:
```cmd
streamlit run app.py
```

### Шаг 4: Откройте в браузере

После запуска в консоли появится адрес, например:
```
Local URL: http://localhost:8501
```

Откройте этот адрес в браузере (Chrome, Firefox, Edge и т.д.)

## Возможные проблемы и решения

### Проблема 1: "python" не является внутренней командой

**Решение:** Python не установлен или не добавлен в PATH
1. Установите Python с https://www.python.org/downloads/
2. При установке поставьте галочку "Add Python to PATH"
3. Перезапустите командную строку

### Проблема 2: "streamlit" не является внутренней командой

**Решение:** Используйте полную команду:
```cmd
python -m streamlit run app.py
```

### Проблема 3: Ошибка при установке зависимостей

**Решение:** Установите зависимости по одной:
```cmd
python -m pip install cianparser
python -m pip install streamlit
python -m pip install pandas
python -m pip install openpyxl
```

### Проблема 4: Не открывается браузер автоматически

**Решение:** Откройте браузер вручную и введите адрес:
```
http://localhost:8501
```

## Остановка приложения

Чтобы остановить приложение:
- Нажмите `Ctrl + C` в командной строке
- Или просто закройте окно командной строки

## Виртуальное окружение (опционально, для продвинутых)

Рекомендуется использовать виртуальное окружение:

```cmd
# Создание виртуального окружения
python -m venv venv

# Активация
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
streamlit run app.py
```

## Быстрый старт (TL;DR)

```cmd
# 1. Откройте папку проекта в проводнике
# 2. В адресной строке введите: cmd
# 3. Выполните команды:

python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Нужна помощь?

Если ничего не помогает:
1. Убедитесь, что Python установлен: `python --version`
2. Убедитесь, что находитесь в правильной папке: `dir` (должны видеть app.py)
3. Проверьте подключение к интернету (для установки зависимостей)
